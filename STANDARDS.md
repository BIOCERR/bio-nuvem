# Overview

BIO – Regenerative AI Platform has been designed following internationally recognized open standards, responsible software engineering practices and ethical Artificial Intelligence principles.

The objective is to promote interoperability, transparency, sustainability and long-term maintainability.

# Open Standards

The public platform is built using open and widely adopted technologies including:

- HTML5
- CSS3
- JavaScript (ECMAScript)
- JSON
- Markdown
- HTTPS
- Git
- GitHub

These technologies promote interoperability, portability and long-term accessibility.
